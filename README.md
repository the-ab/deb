# the-ab APT repository

Shared signed APT repository for ODROID and other the-ab projects. Planned address: https://the-ab.github.io/deb/

Project sources and binary/source releases remain in their product repositories. This repository contains the public archive key, signed package indices and published small Debian packages. Private signing keys must never be committed. Initial components: main (shared infrastructure) and u3 (ODROID-U3).

Repository setup does not automatically publish or approve new kernel releases.
